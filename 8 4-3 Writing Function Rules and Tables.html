Section 2 • 5 Minutes Direct Instruction

Objective 1: Writing Function Rules

Example Problem Statement:

A local tech squad charges $9 per hour for computer repair services plus a basic fee of $100. How can we determine the total cost of the services for 12 hours?

Step 1: Write a Function Rule

Let c = the total cost (dependent variable).
Let h = the number of hours (independent variable).

The basic fee ($100) is a constant, and the hourly charge ($9) depends on the hours.
Rule: c(h) = 100 + 9h

Step 2: Substitute and Solve

Substitute the 12 hours into our rule for h.

c(12) = 100 + 9(12)
c(12) = 100 + 108
c(12) = 208

The total cost for 12 hours is $208.

Anatomy of a Word Problem Rule
c(h) = 100 + 9h
c(h) is the Total Output Cost
100 is the One-Time Constant Fee
9h is the Repeating Hourly Rate

Objective 2: Making Function Tables

Example Problem Statement:

Given a function table, find the pattern to write a rule that expresses the relationship between x and y. Then find the missing y-value when x = 94.

Input (x)
Output (y)

101

Step 1: Test Patterns

Look at the x and y values. Since the y-values are greater, test addition or multiplication.
91 + 10 = 101. True.
92 + 10 = 102. True.
93 + 10 = 103. True.
The rule is y = x + 10.

Step 2: Solve the Missing Value

Apply the rule to the target input x = 94.

y = 94 + 10
y = 104

The missing value for the table is 104.

Section 6

Key Takeaways & Save / Turn In

1. Writing Rules

When writing a rule from a word problem, identify the one-time constant basic fee and the rate that changes depending on the independent variable.

2. Function Tables

To find a rule from a table, test patterns (addition or multiplication) between the x and y values to see which rule holds true for every row.
