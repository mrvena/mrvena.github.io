Today's Learning Objective

I can use the order of operations to simplify expressions with decimals and fractions, and I can solve addition and subtraction equations that include fractions.

Section 1

Why We Need This Math & Key Vocabulary

Baking & Recipes

Example: If a recipe calls for 1/2 cup of sugar and you already added 1/8 cup, subtraction equations help you find out exactly how much more you need.

Carpentry & Building

Example: When measuring wood, fractions are everywhere! You might need to add or subtract fractions of an inch to ensure two pieces fit together perfectly.

Computer Programming

Example: Computers must follow an exact order to calculate logic. The order of operations ensures software formulas process complex decimals correctly.

Finance & Budgets

Example: Money involves decimals! If you are balancing a budget with many operations, completing multiplication before addition ensures an accurate total.

Key Vocabulary Terms

Order of Operations: The rules stating which math operations to perform first (PEMDAS).
Grouping Symbols: Parentheses ( ), brackets [ ], or a large division bar that tell you what to calculate first.
Variable: A letter (like x or y) that represents an unknown numerical value in an equation.
Addition Property of Equality: If you add the same number to both sides of an equation, it stays balanced.
Subtraction Property of Equality: If you subtract the same number from both sides, it stays balanced.
Inverse Operations: Operations that undo each other, like addition and subtraction!
Section 2 • 5 Minutes Direct Instruction

Objective 1: Order of Operations with Rational Numbers

Remember: PEMDAS
Example Problem Statement:

Simplify the following expression using the order of operations:
( 4² - 6.5 ) / ( ( 5 - 12 ) + 3² )

Step 1: Simplify the Numerator (Top)

The top part of the fraction bar acts as its own grouping symbol.
First, do the exponent: 4² = 16.
Next, subtract: 16 - 6.5 = 9.5.

Step 2: Simplify the Denominator (Bottom)

The bottom acts as another grouping symbol.
Parentheses first: ( 5 - 12 ) = -7.
Exponent next: 3² = 9.
Add them together: -7 + 9 = 2.

Step 3: Divide

The large fraction bar means division.
Divide the top by the bottom: 9.5 / 2 = 4.75.

Expression Breakdown
( 4² - 6.5 )
( (5 - 12) + 3² )
9.5
2
= 4.75

Error to Avoid: Division Bar Rules!

Always treat the numerator (top) and the denominator (bottom) as if they are in invisible parentheses. Simplify everything on top first, then everything on bottom, and divide as the very last step.

Problem 1 (Partner Work)
Problem Statement: Simplify the following expression using the order of operations:
( -1/2 )² ÷ ( 1/4 )²
The evaluated result of the fraction expression:

• Simplify the exponents first. (-1/2) × (-1/2) is a positive number.

• To divide by a fraction, multiply by its reciprocal!

Problem 2 (Partner Work)
Problem Statement: Simplify the complex fraction:
( -8.5 + 2.5 ) / ( 2/3 × 3/4 )
The simplified integer result of the expression:

• Simplify the numerator by adding the decimals.

• Simplify the denominator by multiplying the fractions, then divide.

Problem Statement: A baker has 15 1/2 cups of flour. He uses 5 1/2 cups for bread, then divides the rest equally into 4 bowls. How many cups of flour are in each bowl?

Section 4 • 5 Minutes Direct Instruction

Objective 2: Addition & Subtraction Equations with Fractions

Keep the balance!
Example Problem Statement:

Solve the equation for the variable x: x + 2/5 = 7/10

Step 1: Isolate the Variable

Problem: We need to get x by itself. Since 2/5 is being added to x, we use the inverse operation.
We must subtract 2/5 from both sides of the equation. (Subtraction Property of Equality).

Step 2: Find a Common Denominator

• We need to calculate: 7/10 - 2/5.
• The common denominator is 10.
• Rename 2/5 as 4/10.
• Subtract: 7/10 - 4/10 = 3/10.
So, x = 3/10.

Equation Balancer
x + 2/5 = 7/10
- 2/5      - 2/5
x = 7/10 - 4/10
Final Value of x: 3/10
Section 5A • 5 Minutes Guided Practice (Partner Work)

Objective 2 Partner Practice (Problems 6–7)

Work together with your partner to isolate the variables!

Problem 6 (Partner Work)
Problem Statement: Solve the following subtraction equation:
y - 1/3 = 5/12
The fraction value of the variable y:

• Use the Addition Property of Equality. Add 1/3 to both sides.

• Find a common denominator before adding. (Hint: 12 works well!)

Problem 7 (Partner Work)
Problem Statement: Solve the equation with a negative fraction:
m + ( -3/7 ) = 2/7
The fraction value of the variable m:

• Since you are adding a negative, it's the same as subtraction.

• To undo it, add a positive 3/7 to both sides.

Section 5B • 5 Minutes Independent Practice (Individual Work)

Objective 2 Independent Practice (Problems 8–11)

Solve for the unknown variables independently!

Problem 8
Problem Statement: Solve the equation:
5/6 = n - 1/6
The value of the variable n:

Add 1/6 to both sides. Make sure to simplify your fraction if it equals a whole number.

Problem 9
Problem Statement: Solve the equation:
x - ( -1/8 ) = 7/8
The fraction value of the variable x:

Subtracting a negative is the same as adding! So this is x + 1/8.

Problem 10
Problem Statement: Solve the equation involving mixed numbers:
p - 3 1/4 = 8 1/2
The value of the variable p:

Add 3 1/4 to both sides. Remember to find a common denominator for the fraction parts.

Problem 11 (Word) Building
Problem Statement: A carpenter cuts a length of wood from a board. He now has 4 1/5 feet left. If the equation is x + 4 1/5 = 9 4/5, where x is the cut amount, what length did he cut?
The length of wood cut in feet:

Subtract 4 1/5 from both sides to find x.

Section 6

Key Takeaways & Save / Turn In

1. Grouping First

Compute operations inside grouping symbols, like parentheses or above and below a large division bar, before anything else!

2. Exponents

Simplify any powers or exponents after grouping symbols, but before multiplying, dividing, adding, or subtracting.

3. Keep it Equal

To solve an equation, whatever you add or subtract on one side, you must add or subtract on the exact same amount on the other side!

4. Inverse Ops

Use addition to undo subtraction, and use subtraction to undo addition when isolating a variable.
