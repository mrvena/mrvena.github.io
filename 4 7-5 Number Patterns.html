Today's Learning Objective

I can use a mathematical rule to make a number pattern in an input-output table and find special features of that pattern.

Section 1

Why We Need This Math & Key Vocabulary

Baking Recipes

Example: If 1 batch of cookies needs 2 cups of flour, you can use a multiply rule to figure out how much flour you need for 4 batches.

Saving Money

Example: If you save 5 dollars every week, you can use an input-output table to predict how much money you will have after many weeks.

Team Sports

Example: If every basketball team requires exactly 5 players, a number pattern tells you how many teams you can form with 30 players.

Reading Goals

Example: If you read 10 pages every night, a pattern rule helps you see exactly what page you will be on by the end of the week.

Key Vocabulary Terms

number pattern: A list of numbers that follow a certain rule to get from one number to the next.
input-output table: A table that shows a pattern of inputs and the outputs created by a specific rule.
rule: The mathematical operation (like Add 3 or Multiply by 2) that changes the input into the output.
input: The starting number you put into the table before applying the rule.
output: The final number you get after the rule has been applied to the input.
multiply: Adding a number to itself a certain number of times. Often used as a pattern rule.
Section 2 • 5 Minutes Direct Instruction

Objective 1: Applying Rules to Inputs

Example Rule: Multiply by 4
Example Problem Statement:

Use the rule Multiply by 4 and input numbers 3, 5, and 7 to write the pattern of output values.

Step 1: Understand the Rule

Problem: Use the rule Multiply by 4 and input numbers 3, 5, and 7 to write the pattern of output values.

The rule for a pattern is the same for all inputs in the pattern. We will multiply each input number by exactly 4.

Step 2: Apply the Rule to Each Input

Problem: Use the rule Multiply by 4 and input numbers 3, 5, and 7 to write the pattern of output values.

• First input is 3. Multiply by 4: 3 × 4 = 12
• Second input is 5. Multiply by 4: 5 × 4 = 20
• Third input is 7. Multiply by 4: 7 × 4 = 28

Input-Output Table
Input Rule Output
3 Multiply by 4 12
5 Multiply by 4 20
7 Multiply by 4 28

Error to Avoid: Changing the Rule!

Always remember that the rule in a pattern stays exactly the same for every input. Do not switch from multiplying to adding halfway through!

Section 4 • 5 Minutes Direct Instruction

Objective 2: Finding Features & Division Rules

Example Problem: Find the Rule
Example Problem Statement:

An input-output table has an input of 60 with an output of 6. It also has an input of 70 with an output of 7. Determine the division rule for this pattern.

Step 1: Look at the Change

Problem: Determine the division rule for this pattern.

Look at how the input numbers change into the output numbers. The numbers are getting smaller (from 60 to 6), which usually means we are dividing or subtracting.

Step 2: Test a Rule

Problem: Determine the division rule for this pattern.

• What do we divide 60 by to get 6? 60 ÷ 10 = 6.
• Let's test the rule Divide by 10 on the next input.
• 70 ÷ 10 = 7. It works!
The rule for this pattern is Divide by 10.

Pattern Test
Input: 60

60 ÷ 10 = 6

Output: 6
Verified Rule: Divide by 10

Section 6

Key Takeaways & Save / Turn In

1. The Rule

The rule for a pattern is exactly the same for all inputs in the pattern. It tells you what math operation to do!

2. Inputs

The input is the starting number. You apply the mathematical rule to this number first.

3. Outputs

The output is the new number that is created after the rule has been applied to the input number.

4. Patterns

You can use an input-output table to make a number pattern and clearly see how the numbers change.
